# Portfolio handoff: web-toys

Ready to file by Hobby Hub on the-broadcast as an issue titled `portfolio: web-toys`.

**Repo:** https://github.com/AQuantumArchitect/web-toys (MIT)
**Home:** https://toys.lukespooner.com

Small, static web toys: no backend, no accounts, no trackers, no external fonts. Vite + React + Tailwind.

## Kid Lobber

- **Live:** https://toys.lukespooner.com/trebuchet/
- **Pitch:** A hammock-trebuchet calculator: set arm, counterweight, sling and fulcrum, and see a landing zone with Peak G, max height and impact speed readouts. Safety bands (SAFE / CAUTION / DANGER) and a side-view diagram make the numbers easy to read at a glance.
- **Origin:** Born from a backyard marble trebuchet built with his kids.
- **Screenshot:** `public/screens/trebuchet.png`

## Layer Roll

- **Live:** https://toys.lukespooner.com/layers/
- **Pitch:** A three-layer pass-the-paper drawing game: roll an outline, mid details and fine details, draw one layer each, and pass the paper. Works for a party or solo, with optional theme packs and seeded rolls via `?seed=`.
- **Origin:** A pass-the-paper drawing game played at the family table.
- **Screenshot:** `public/screens/layers.png`

## Honest limits

- Kid Lobber uses simplified physics. It is a rough-estimate toy, not engineering advice. Never launch a person; test only with sandbags.
- Layer Roll's tables are original, inspired by the layered-prompt idea in *Fantasy Genesis*. No word lists, layouts or text are copied, and it is not affiliated with that book.
